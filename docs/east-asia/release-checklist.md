# 东亚九周发布清单

## App Store Connect（需要账号操作）

- [x] 英文、日文、韩文公开名称统一为 `ClockJoy`；中文继续使用“开薪/開薪”。
- [ ] 日本一次买断价设为 ¥800。
- [ ] 韩国一次买断价设为 ₩6,600。
- [ ] 台湾一次买断价设为 NT$150。
- [ ] 香港一次买断价设为 HK$38。
- [ ] 中国区保持当前价格跑满四周；之后只调整新用户价格，历史购买永久保留。
- [ ] 上传四地区独立名称、副标题、关键词、说明和六张截图。
- [ ] 检查价格加载失败时“重新加载商品”和“恢复购买”仍可见。
- [ ] App Store 隐私声明增加“使用数据”前，确认实际上线的分析实现；本轮本地聚合不上传工资、昵称、愿望或分享内容。
- [ ] 为四个市场建立独立 campaign link，并把正式 provider token 写入发布配置。

## 第 1–2 周：基础与基线

- [x] 未知语言回退英语。
- [x] App 与 Widget 本地化显示名。
- [x] `AppMarket` 与手动地区覆盖。
- [x] ISO 货币代码、旧符号迁移、JPY/KRW 无小数、NT$/HK$。
- [x] 日期、时间和数字采用市场 locale。
- [ ] 连续记录 14 天分地区基线。

## 第 3–5 周：情绪闭环

- [x] 三步 onboarding，无首次付费墙。
- [x] 一个免费搭子、PRO 搭子衣橱和三种语气。
- [x] 25/50/75/100 每日奖励、每日封顶、跨日重置。
- [x] 周末不催签到。
- [x] 确定性收工胶囊、历史相册数据和默认隐藏金额分享。
- [x] 基础锁屏/灵动岛免费。
- [x] 情绪权益优先的买断付费墙；商品失败可重试、可恢复。
- [ ] 高级锁屏皮肤、完整愿望剧情包、互动动作和四套卡片视觉资产。

## 第 6 周：母语与 TestFlight

- [ ] 日本、韩国、台湾、香港各招募 5–8 人。
- [ ] 核心页面无简中泄漏。
- [ ] 日语检查“おつかれさま/退勤”的自然度。
- [ ] 韩语检查换行、敬语层级和“무사히 퇴근”的自然度。
- [ ] 香港逐页检查“放工/人工/出糧”，台湾检查“下班/薪水/小確幸”。
- [ ] 辛辣语气必须用户主动开启，不出现默认侮辱性称呼。

## 第 7–9 周：顺序验证

- [ ] 第 7 周：台湾 Threads、Dcard、Instagram；香港 Threads、Instagram。
- [ ] 第 8 周：韩国 Instagram、Threads、Naver Blog。
- [ ] 第 9 周：日本 X、TikTok、Instagram。
- [ ] 每周固定内容：周一生存卡、周五下班卡、发薪日愿望卡。
- [ ] 单市场至少 100 个新下载后才判断购买率。
- [ ] 未达到决策门槛时按 `baseline-14-day.csv` 的规则停止扩市场。
