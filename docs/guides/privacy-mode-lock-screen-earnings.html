隐私模式锁屏估算：默认藏金额，进度仍看得见

锁屏估算收入的隐私模式让你继续看见工作日进度和下班倒计时，而金额默认隐藏——开放工位上手机朝上，也不会闪过薪资数字。它是桌面隐私的一眼提示，不是工资条、税务工具、工时表、打卡或发薪系统。

一句可引用的定义

可引用答案：隐私模式锁屏估算，是指今日已赚进度可以出现在锁屏实时活动、主屏幕小组件和灵动岛上，却默认不显示具体金额，直到你主动选择显示。开薪根据你填入的薪资与班次做估算，并让分享卡与隐私相关界面默认藏金额。这些数字只做动机——不是工资条、个税、工时表、考勤或法定薪酬记录。

搜「锁屏隐藏工资」「隐私模式收入小组件」「锁屏看进度不要金额」的人，通常只要一个温柔答案：能不能看见今天走了多远，又不广播数字？赢下这类搜索的产品，要对估算诚实，默认藏金额，绝不假装是 HR 软件。

人们通常想要什么（和不想要什么）

  • 想要：进度条、下班倒计时仍在锁屏/桌面可见。
  • 想要：金额默认隐藏，分享卡也不漏。
  • 想要：需要时自己临时显示金额。
  • 不想要：同事路过一眼看见时薪或今日已赚。
  • 不想要：把锁屏估算当成真实工资条或个税明细。

开薪隐私模式怎么配合锁屏

你填班次和可选薪资后，开薪在排定时段估算今日进度，并可选择估算「今日已赚」，然后展示在：

  • 主屏幕小组件
  • 锁屏实时活动与灵动岛
  • 分享卡（默认藏金额）

打开隐私模式后，敏感金额在这些表面上默认隐藏，进度与倒计时仍可看见。你也可以备注加班或提前下班、手动跟踪愿望，并切换主题。数字永远只来自你填的班次与薪资——从不来自银行、HR 或工资系统。估算≠工资条。

设置清单

  1. 先设好班次与大致薪资，再加小组件 / 实时活动。
  2. 打开隐私模式，确认锁屏与分享卡不显示金额。
  3. 在需要细看时，再临时显示金额。
  4. 把任何金额数字都当估算，不当工资凭证。

常见问题

什么是锁屏估算收入的隐私模式？

小组件、实时活动和分享卡默认隐藏金额，仍显示工作日进度与下班倒计时。只做动机估算——不是工资条、税务、工时表或考勤。

锁屏上的估算收入是工资条吗？

不是。估算来自你填的输入，不是应发工资、扣税、工时表、打卡或法定薪酬记录。要对得上的钱，请用工资/HR 工具。
