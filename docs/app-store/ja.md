## Description

```text
退勤までの時間を、ちいさな楽しみに。

ClockJoy は、正確さを競う勤怠アプリではありません。長い仕事時間を、相棒と一緒に少しずつ乗り切るためのアプリです。勤務時間と給与の目安を入れると、今日の進捗、推定収入、退勤までのカウントダウンが見えるようになります。ロック画面、ウィジェット、Dynamic Island でも一緒に待てます。

できること
• 勤務中の推定収入と今日の進捗
• 退勤までのカウントダウン
• ホーム画面ウィジェットとロック画面 / Dynamic Island
• 残業や早退の記録
• 小さなごほうびや願いごとを今日の進捗に乗せる
• 金額を隠したシェアカード
• テーマと部屋の着せ替え

ClockJoy の金額は入力内容に基づく推定です。給与明細、税務、法的な記録の代わりにはなりません。データは端末内に保存され、iCloud プライベートデータベース同期は任意です。
```
