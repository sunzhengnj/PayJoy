## Description

```text
退勤までの時間を、ちいさな楽しみに。

ClockJoy は、正確さを競う勤怠アプリではありません。長い仕事時間を、相棒と一緒に少しずつ乗り切るためのアプリです。勤務時間と給与の目安を入れると、今日の進捗、推定収入、退勤までのカウントダウンが見えるようになります。ロック画面のライブアクティビティと Dynamic Island でも一緒に待てます。

できること
• 勤務中の推定収入と今日の進捗
• 退勤までのカウントダウン
• ロック画面のライブアクティビティと Dynamic Island
• 25分・45分・カスタムの集中タイマー。退勤間際は終業まで集中
• タイマーは一つの時間を大きく表示。一時停止・再開し、終了後に実際の集中時間を確認
• 残業や早退の記録
• 小さなごほうびや願いごとを今日の進捗に乗せる
• 金額を隠したシェアカード
• テーマと部屋の着せ替え

ClockJoy の金額は入力内容に基づく推定です。給与明細、税務、法的な記録の代わりにはなりません。データは端末内に保存され、iCloud プライベートデータベース同期は任意です。
集中時間が収入や願いごとの進捗に自動で加算されることはありません。

Terms: https://sunzhengnj.github.io/PayJoy/ja/terms.html
```
