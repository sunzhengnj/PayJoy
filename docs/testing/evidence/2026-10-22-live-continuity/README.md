2026-10-22，Xcode 27.1（27A9275）、iOS 27.1（24A94425）、PayJoy Verified Duo，Debug 1.6(11)。本轮一次只运行一台模拟器、一个测试任务。未使用截图模式或冻结时钟。

## 实际流程

完成测试机首次引导 → 从首页进入专注 → 自定2分钟 → 展开横向运行 → 书本运行 → 黑色外观、暂停 → 桌面姿态 → 合上并终止应用 → 重启恢复01:32 → 继续 → 桌面、展开竖向、书本 → 自然到点 → 结果02:00 → 再次终止与重启。

`focus-inner.mov` 为内屏连续原片，合上时内屏不显示外屏；外屏及重启恢复另有窗口截图。`persistence.jsonl` 为每一步从模拟器应用偏好读取的会话快照。首次暂停后磁盘写入有延迟，`paused-book` 尚为旧值，以之后 `paused-book-flushed` 和终止后的快照为准。

## 发现及修正

恢复专注时选中标签初始化为首页，全屏计时呈现前会露出收入内容。新增两个AppState回归测试，分别恢复暂停会话和待查看结果：旧代码均以 home != focus 失败（`restore-red.log`）；修订后恢复到专注标签，完整136项iOS XCTest通过（`restore-green.log`、`restore-green-summary.json`）。初始化不主动请求旋转，避免尚未收到铰链识别时按普通手机请求竖屏；普通手机的默认方向及手动旋转入口保留。

`restored-result-fixed.mov`、15–17号截图为修订后的正常结果恢复。启动早期保留品牌页，随后呈现专注结果；系统折叠分区回调期间短暂从单区布局进入书本分区，不等于所有中间角度均验收通过。没有重新结算。

截图脚本原本拒绝复用已启动设备。新增复用测试先复现拒绝（`capture-reuse-red.log`）；修正后复用测试及原有主机就绪、构建互斥、两台上限、启动失败清理和状态栏检查通过（`capture-reuse-green.log`）。脚本只关闭由自己启动的设备，复用设备由调用方负责。
