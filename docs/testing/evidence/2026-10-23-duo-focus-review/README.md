## 重新展开的黑帧

三轮合上／展开：首次内屏取图均为全黑；等待约3秒后的取图均恢复，无需旋转。合上时外屏有内容，不能把此时内屏全黑当成应用故障。`paused-reopen-*.png`、`paused-cycle-*.png` 与 `reopen-events.jsonl` 留存取屏及操作时序；`focus-reopen-inner.mov` 是前半段连续内屏原片，合上期间的黑画面符合该显示器未使用的状态。

本轮未复现原“必须旋转后才恢复”的持续黑屏，也没有增加强制重建、旋转或延时补丁。最初Device Hub还曾呈侧面视角，内屏未渲染，该次启动截图单独保留，不能充当专注黑屏的复现。姿态变化后的早期画面也可能仍是旧界面，后续操作须先确认当前画面；不据未送达的点击推断业务状态。
