# 重启后候选版本实测清单

更新于 2026 年 10 月 23 日。恢复卷可读，Duo 已成功运行应用，Device Hub 可见。用户已撤销按高 CPU 自动关闭的限制；继续遵守最多两台模拟器、一个构建／测试任务。外屏边界、内屏比例及分栏已有修订；当前继续全姿态、计时连续性与全应用验收，尚未全部通过。

## 启动前条件

- 保存现有工作，用户自行决定重启时间；本任务不执行系统重启。
- 检查运行中的模拟器和构建／测试进程。优先复用 PayJoy Verified Duo，只开一台；最多两台，构建／测试任务最多一个。启动初始化期间不并行编译。
- 重新核对 Xcode、运行时和设备登记，不能假定重启前的状态持续有效。当前参考为 Xcode 27.1（27A9275）、iOS 27.1（24A94425）；运行时登记 `2F27E9A4-1309-4303-A4AF-9452FA479668`，设备 `A199B0FE-1420-4D85-A191-5E91A9C10FCF`。
- 记录宿主 CPU、内存与交换内存基线。重启不能保证解决故障；允许正常初始化与测试，高 CPU 本身不作为关闭条件；实际失败时保留诊断和设备数据，不删除设备。用户反馈卡顿或要求停止时立即响应。
- 应用界面测试前，用当前源码单任务重建并记录构建号和源码哈希。旧截图、旧 Release 包不代表后续修订。
