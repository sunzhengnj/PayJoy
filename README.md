# 开薪 / ClockJoy

「开薪」（中文）/ `ClockJoy`（英文）是一款原生 SwiftUI iOS App，用漫画化方式展示工作时间内的实时收入、今日进度、下班倒计时、统计、小组件和锁屏/灵动岛实时活动。工程目录、Bundle ID、CloudKit 容器和内部类型名继续保留 `PayJoy`，不作为海外公开品牌使用。
